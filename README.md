# London Bartender Recruitment Bot

Telegram-бот для отбора кандидатов на позицию бармена + веб-дашборд с результатами.

## Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Укажи токен бота
```bash
export BOT_TOKEN="твой_токен_от_@BotFather"
```

### 3. Запусти бота (в одном терминале)
```bash
python bot.py
```

### 4. Запусти дашборд (в другом терминале)
```bash
python dashboard.py
```
Открой браузер: **http://localhost:5000**

---

## Структура проекта

| Файл | Назначение |
|------|-----------|
| `bot.py` | Telegram-бот, диалог с кандидатом |
| `dashboard.py` | Веб-дашборд Flask |
| `questions.py` | 10 вопросов теста (редактируй под себя) |
| `db.py` | SQLite-база данных |
| `recruitment.db` | База данных (создаётся автоматически) |

---

## Как пользоваться дашбордом

- Таблица кандидатов отсортирована по баллу (лучшие сверху)
- 🟢 ≥70% — хороший кандидат
- 🟡 40–69% — средний
- 🔴 <40% — слабый
- Кнопка **«Детали»** — раскрывает все вопросы, ответы кандидата и пояснения к ошибкам
